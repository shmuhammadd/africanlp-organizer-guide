# Organising AfricaNLP

A guide for anyone who runs the AfricaNLP workshop, built with Docusaurus. It starts from what the AfricaNLP 2027 organisers did.

## Run locally

```bash
npm ci
npm start      # http://localhost:3000/africanlp-organizer-guide/
npm run build  # static site in build/
```

## Edit

- Chapters live in `docs/chapters/`, numbered in reading order. The number is dropped from the URL.
- Email templates live in `docs/templates/`.
- The sidebar order is in `sidebars.js`.
- Each chapter ends with a **TODO** list of gaps to fill.

Never commit passwords, account logins or personal email addresses of speakers or authors.
