title: "5. Drive, email, Slack and website"
---

Set these up in the week after the proposal is accepted. Authors will use the contact address and the website from the first call onwards.

## Google Drive

1. Open the shared AfricaNLP folder in Drive. Ask the previous general chair for access.
2. Create a folder for the year, such as `AfricaNLP2027`.
3. Copy last year's folder into a subfolder of it. The emails, call text and speaker letters get reused.
4. Keep one "Important documents, links and deadlines" doc at the top: contact address, website, roles, dates.

## Contact address

Create a Google Group for the year. 2027 used `africanlp-eacl2027@googlegroups.com`.

- Add every organiser.
- Allow posts from non-members, because authors write to it.
- Put it on the website, in OpenReview and as the reply-to on every email.

## Slack

- Private channel `africanlp20XX` in the Masakhane workspace for the organisers.
- Public channel `africanlp-<venue><year>-support` for authors and anyone with questions. Link it from the website.

## Social media

- X (Twitter) handle: `@Africa_NLP`. The login belongs to the shared workshop Gmail account. Ask the previous communication chair for it. Never write the password into a document.

## Website

Until 2026 the website was a Google Site, copied from the year before. From 2027 it is a static site on GitHub Pages at [africanlp.github.io/2027](https://africanlp.github.io/2027/home).

1. Copy last year's site for the new year.
2. Update the title, year, theme, topics, organisers, speakers and dates.
3. Use "TBA" for any date not yet fixed.
4. Give each organiser who edits it write access to the repository.
