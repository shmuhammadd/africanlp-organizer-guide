---
title: "8. ARR commitments"
---

Papers already reviewed in ACL Rolling Review can be committed to the workshop with their reviews. A separate OpenReview venue receives them. Authors paste the link to their ARR submission. Nobody reviews them again.

As of 17 November 2026 this venue was still to be set up for 2027.

## Request the venue

1. On the [OpenReview Support page](https://openreview.net/group?id=OpenReview.net/Support), click **OpenReview Support Venue Request ARR Commitment Workflow**.
2. Use the same website, location, start date, chair emails and contact address as the main venue.
3. Set:
   - Name: 8th Workshop on African Natural Language Processing (ARR Commitment)
   - Abbreviated name: AfricaNLP 2027 ARR Commitment
   - Deadline: 2026-12-23 12:00 GMT (= 22 Dec AoE)
   - Expected submissions: about 20
4. In **Other Important Information**, say this is the ARR side of a hybrid venue. Give the main venue ID, the eligible ARR cycles (2027: October 2026 or earlier) and the requested ID, such as `eacl.org/EACL/2027/Workshop/AfricaNLP_ARR_Commitment`. Ask for author responses to be included.

## After deployment

1. Put the commitment link on the call page. The form's `paper_link` field checks that the link points to a real ARR submission.
2. **The day after the commitment deadline**, email OpenReview Support to grant access to the committed papers' reviews and meta-reviews. This is not automatic. Holiday closures make it urgent.
3. Decide using the ARR meta-reviews.
4. Accepted ARR papers follow the same camera-ready deadline as direct submissions.

See OpenReview's ARR Commitment Venues page.
