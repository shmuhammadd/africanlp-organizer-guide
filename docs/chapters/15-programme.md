The host sends a form asking for the shape of your day. Answer it early. Room sizes and poster boards depend on it.

## The host's form

These were our answers:

| Question | Answer |
|---|---|
| Virtual platform (Gather) needed? | No |
| Poster PDF mandatory? | Yes, and mandatory for virtual posters |
| Poster video length | 10 minutes, strict |
| In-person poster session | Afternoon slot, 12:00–13:00 |
| Number of posters | 40 |
| Oral pre-recording mandatory? | Yes, 10 minutes, strict |
| Oral slides mandatory? | Yes |
| Certificates or awards? | Yes |
| ACL staff help with awards? | No |
| Monetary awards? | No |
| Start time | 09:00 (no earlier than 08:30) |
| End time | By 18:00 |

The host fixes coffee breaks at 10:30–11:00 and 15:30–16:00. Plan around them. No exceptions are made.
