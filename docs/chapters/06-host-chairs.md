title: "6. Information for the host's workshop chairs"
---

The host conference's workshop chairs run every workshop through one shared spreadsheet. For 2027 it was "EACL 2027 Workshop Information". They use it for the conference website, the programme, rooms, registration, visas and the proceedings. Each workshop fills in its own row. Ask the chairs for the link if you do not have it.

Keep the AfricaNLP row up to date all year. The chairs chased most workshops several times in 2026 for missing cells. Cells they need are highlighted in red.

## The tabs

The 2027 sheet had four tabs. Each row starts with the workshop ID the host assigns. AfricaNLP was **7** in 2027.

### General Workshop Info

| Column | What to enter | 2027 entry |
|---|---|---|
| Workshop | Full name | The 8th Workshop on African Natural Language Processing (AfricaNLP) |
| Duration (days) | Number of days | 1 |
| Estimated # participants | Expected attendance, for room size | 60 |
| Workshop URL | Website | https://africanlp.github.io/2027/home |
| Short description | Two or three sentences for the host's workshop page. See last year's host page for examples. | See below |

The 2027 description:

> AfricaNLP brings together researchers working on NLP for African languages. The 2027 theme, "From Research to Real-World AfricaNLP Applications," focuses on turning African-language datasets, benchmarks and models into systems people use, covering real-world evaluation, compute constraints, data governance and long-term maintenance.

The tab also has three tick boxes: Organizers tab done, Submission Platform tab done, ISBN tab done. The chairs use them to track who has finished.

### Workshop Submission Platform Info

| Column | What to enter | 2027 entry |
|---|---|---|
| Primary contact | The general chair's institutional email | General chair |
| Workshop acronym | Acronym and year, no space | AfricaNLP2027 |
| Website | Website | https://africanlp.github.io/2027/home |
| Platform | OpenReview or Softconf | OpenReview |
| Submission site | The public OpenReview venue page | https://openreview.net/group?id=eacl.org/EACL/2027/Workshop/AfricaNLP |

Fill in the submission site as soon as the venue is live. See [OpenReview setup](openreview).

### Workshop Organizer Info

List every organiser by full name, in the order you want them printed, with every email. The host uses this list for the website, the proceedings front matter and registration. Use the same names and order as on the AfricaNLP website.

2027 listed 14 organisers: seven in the main columns and seven under Additional Organizers.

### ISBNs

| Column | What to enter | 2027 entry |
|---|---|---|
| Proceedings title | The exact title for the ACL Anthology | Proceedings of the 8th Workshop on African Natural Language Processing (AfricaNLP 2027) |
| ISBN # | Filled in by the host | |
| Date filed | Filled in by the host | |

The host requests the ISBN only after you confirm the title. Check it for typos. It goes onto the Anthology volume and cannot change later.

## Later in the year

The chairs add more requests to the same sheet, or to a second one, as the conference gets closer. In 2026 they asked for:

- The number of oral presentations, posters and Findings papers.
- The list of accepted papers and their authors. They use it for visa letters and to check that every paper has a registered author.
- Poster boards needed.
- The name of the person who gets the workshop's one complimentary registration, usually an invited speaker.
- The programme: start time, lunch, end time. Coffee breaks are fixed by the host.

Answer within a few days. Rooms are assigned from these numbers.
